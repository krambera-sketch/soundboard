Put your audio files in this folder (MP3, WAV, M4A, OGG, AAC, FLAC).

Folders become sections on the board:
  sounds/Intros/airhorn.mp3     -> section "Intros", sound "airhorn"
  sounds/Insults/boo.wav        -> section "Insults", sound "boo"
  sounds/laugh.mp3              -> section "Sounds"

Start a name with a number to control the order. The number is hidden on the page:
  sounds/01 Intros/01 airhorn.mp3
